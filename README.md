# FORMA — Objects, Designed Differently.

A premium, experimental 3D and cinematic e-commerce showroom for luxury industrial design objects.

## Tech Stack
- **Framework**: React 18, Vite
- **Styling**: Tailwind CSS
- **Scroll & Animations**: GSAP ScrollTrigger, Lenis Smooth Scroll
- **Icons**: Lucide React
- **Video Engine**: High-GOP keyframe-scrubbed cinematic showroom architecture

## Getting Started

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

## Features
- **Cinematic Showroom**: Smooth scroll-scrubbed 4K video storytelling with zero-dip layered crossfading and GOP=4 faststart video architecture.
- **Curated Object Catalog**: Minimalist gallery showcasing high-craft industrial objects with interactive atelier allocations.
- **Product Inspection**: Responsive product detail modal with comprehensive specs, color selector, quantity manager, and integrated Lenis scroll coordination.
- **Atelier Reserve Cart**: Slide-out luxury checkout drawer with instant total calculation and escrow confirmation.
